== 2. Neo4j Desktop : Configuration, Exécution et Visualisation

NOTE: Ce guide s'appuie sur la **documentation APOC Extended (v2026)** et la **documentation Neo4j Desktop (v2.x)**.

=== Étape 2.1 : Configuration de l'Environnement
Avant d'exécuter des scripts, vérifiez que votre environnement Neo4j Desktop est entièrement configuré à l'aide de la documentation officielle :

* **https://neo4j.com/docs/desktop/current/operations/instance-management[Créer une Instance Locale] :** Suivez les étapes pour créer un nouveau SGBD local.

NOTE: le répertoire https://neo4j.com/docs/desktop/current/operations/instance-management/#_data_path[$NEO4J_HOME] est directement accessible depuis la carte de votre instance via `Open Folder`.

* **https://neo4j.com/labs/apoc/2026/installation/#neo4j-desktop[Installer le Plugin APOC extended] :** APOC est requis pour l'exécution avancée de scripts. Prenez note de la https://neo4j.com/labs/apoc/2026/installation/#_version_compatibility_matrix[Matrice de compatibilité des versions].

NOTE: si le fichier `apoc.conf` n'existe pas dans le répertoire de configuration (`$NEO4J_HOME/conf/`), créez-le et modifiez-le comme indiqué.

* **Activer la Lecture de Fichiers :** Vous devez https://neo4j.com/labs/apoc/2026/overview/apoc.cypher/apoc.cypher.runFile/#_reading_from_a_file[autoriser APOC à lire des fichiers locaux].

=== Étape 2.2 : Création de la Base de Données et Exécution du Script
Une fois l'environnement correctement configuré :

1. **Créer la Base de Données Cible :** https://neo4j.com/docs/desktop/current/operations/instance-management/#_startstoprestart_instance[Démarrez votre instance] et https://neo4j.com/docs/desktop/current/operations/database-management/#_create_a_new_database[créez la base de données] qui hébergera votre graphe (ex. ontograph | relgraph | ontorelgraph).
2. **Préparer le Script :** Déplacez votre script cible (par ex. `OntoRelGraph.cypher`) dans le répertoire d'importation de la base de données (`$NEO4J_HOME/import/`).
3. **Exécuter le Script :** Basculez vers https://neo4j.com/docs/desktop/current/query/[l'interface **Query**]. https://neo4j.com/docs/desktop/current/query/#:~:text=Connect%20to%20your%20instance%20via%20the%20connection%20dropdown%20and%20select%20your%20database.[Connectez-vous à votre instance et sélectionnez votre base de données]. Exécutez la commande suivante pour lancer votre fichier :
+
[source,cypher]
----
CALL apoc.cypher.runFile("OntoRelGraph.cypher")
----
_(Référence : https://neo4j.com/labs/apoc/2026/overview/apoc.cypher/apoc.cypher.runFile/#usage-apoc.cypher.runFile[Utilisation de apoc.cypher.runFile])_

=== Étape 2.3 : Visualisation des Sous-Graphes Démos
Une fois que le script a été exécuté avec succès et a généré votre graphe, vous pouvez filtrer et visualiser un sous-graphe spécifique.

Selon si vous avez roulé OntoRelGraph.cypher pour MONDIAL ou MPHPO copiez la requête correspondante ci-dessous, collez-la directement dans https://neo4j.com/docs/desktop/current/query/#_cypher_editor[l'editeur Cypher], puis appuyez sur `Ctrl + Entrée` (ou cliquez sur le bouton Lecture) :

[[target-cypher-query]]
==== MONDIAL
[source,cypher]
----
WITH [
  'decimal',
  'Measurement_value_decimal',
  'Measurement',
  'YearlyMeasurement',
  'YearlyMeasurement_year_Literal',
  'Literal',
  'YearlyMeasurement_year_nonNegativeInteger',
  'nonNegativeInteger',
  'PopulationCount_population_nonNegativeInteger',
  'PopulationCount',
  'hadPopulation',
  'Country_hadPopulation_PopulationCount',
  'Country'
] AS targetIds
MATCH (n)-[r]->(m)
WHERE n.relId IN targetIds AND m.relId IN targetIds
RETURN n, r, m
----

==== MPHPO
[source,cypher]
----
WITH [
  'string',
  'MPHPO_0000006_Ontorel-Core_0000002_string',
  'MPHPO_0000006',
  'HOSO_0000084',
  'HEPRO_0000010_IAO_0000219_NCBITaxon_9606',
  'IAO_0000219',
  'HOSO_0000084_IAO_0000219_HOSO_0000079',
  'HEPRO_0000009',
  'HEPRO_0000010',
  'NCBITaxon_9606'
] AS targetIds
MATCH (n)-[r]->(m)
WHERE n.relId IN targetIds AND m.relId IN targetIds
RETURN n, r, m
----

== 3. AgensGraph

[NOTE]
====
L'exécution d' `OntoRelGraph` n'est pas supportée pour AgensGraph. Cela est dû à une limitation d'AgensGraph où les sommets ne peuvent avoir https://tech.skaiworldwide.com/docs/en/agensgraph/13/developer_manual/introduction.html#:~:text=each%20vertex%20may%20have%20zero%20or%20only%20one%20label.[qu'une seule étiquette ou aucune], ce qui est incompatible avec la structure multi-étiquettes actuellement implémentée dans `OntoRelGraph`.
====

=== 3.1 Serveur de Graphe : Création de l'Instance et Exécution du Script

[NOTE]
====
Les instructions ci-dessous sont basées sur une installation locale d'**AgensGraph (version 2.x ou supérieure)**, qu'elle ait été réalisée via les **binaires Linux x86-64** ou compilée depuis le **code source**.
====

==== Étape 3.1.1 : Initialisation de la Base de Données et du Schéma de Graphe
1. Ouvrez le terminal de votre système ou votre invite de commande.
2. Accédez à l'outil d'interface en ligne de commande interactif (`agens`) en exécutant la commande de connexion (ajustez les paramètres pour votre utilisateur personnalisé si nécessaire) :
+
[source,bash]
----
agens -U postgres -d postgres
----
3. Initialisez une base de données propre destinée au stockage de votre graphe :
+
[source,sql]
----
CREATE DATABASE agens;
\c agens
----
4. Créez votre objet de schéma de graphe de propriétés cible, puis ajustez le chemin d'accès d'exécution pour en faire votre espace de travail actif :
+
[source,sql]
----
CREATE GRAPH relgraph;
SET graph_path = relgraph;
----

==== Étape 3.1.2 : Exécution du Script openCypher
1. Quittez le shell interactif ou ouvrez un nouvel onglet de terminal. Exécutez votre fichier de script openCypher directement sur votre schéma fraîchement configuré à l'aide de l'option `-f` :
+
[source,bash]
----
agens -U postgres -d agens -f /chemin/vers/votre/OntoRelGraph.cypher
----
+
_(Alternativement, vous pouvez copier les clauses de votre script et les coller directement dans votre invite interactive `agens` active après avoir défini le `graph_path`)._

=== 3.2 AGViewer : Installation, Exécution et Visualisation [OPTIONNEL]

[NOTE]
====
AGViewer est une application web Node.js. Les instructions suivantes sont entièrement multiplateformes et fonctionneront nativement sur **Windows, macOS et Linux**, à condition que **Node.js** (et npm) soit installé sur votre système.

Assurez-vous que votre instance de base de données AgensGraph est déjà active et tourne en arrière-plan avant d'essayer de connecter le visualiseur.
====

==== Étape 3.2.1 : Installation
1. Téléchargez le code source ou l'archive de la version d'AGViewer depuis le dépôt officiel et extrayez-le à l'emplacement de votre choix.
2. Ouvrez votre terminal système ou votre invite de commande (ex : PowerShell, Bash) et naviguez vers le répertoire extrait :
+
[source,bash]
----
cd chemin/vers/AgensGraphViewer
----
3. Installez les dépendances requises des modules Node.js :
+
[source,bash]
----
npm run setup
----
+
_(Note : Si `npm run setup` échoue selon votre version, la commande standard `npm install` fonctionne généralement comme solution de repli)._

==== Étape 3.2.2 : Lancement de l'application
1. Démarrez le serveur web AGViewer. Vous pouvez le lancer en utilisant la commande standard du gestionnaire de paquets Node :
+
[source,bash]
----
npm start
----
+
2. Une fois le serveur initialisé, ouvrez votre navigateur web préféré et accédez à l'adresse du serveur local :
+
[source,plaintext]
----
http://localhost:3000
----

==== Étape 3.2.3 : Connexion à AgensGraph
1. Sur l'écran d'accueil d'AGViewer, entrez les identifiants de connexion de votre base de données active :
* **Type de base de données :** AgensGraph
* **URL de connexion :** `127.0.0.1` (ou l'adresse IP spécifique de votre hôte)
* **Port de connexion :** `5432` (ajustez à `5455` ou similaire si vous avez mappé un port différent via Docker)
* **Nom d'utilisateur et Mot de passe :** Les identifiants de votre base de données (ex : `postgres` / `agens`)
* **Nom de la base de données :** La base de données que vous avez créée (ex : `agens`)
2. Cliquez sur le bouton de connexion pour établir le lien et commencer à visualiser votre chemin de graphe actif (`relgraph`).

==== Étape 3.2.4 : Visualisation des Sous-Graphes Démos
1. Une fois connecté avec succès, repérez la barre de saisie de l'**Éditeur de requêtes** (Query Editor) en haut de l'espace de travail d'AGViewer.
2. Selon si vous avez roulé OntoRelGraph.cypher pour MONDIAL ou MPHPO copiez la requête cible correspondante  définie précédemment dans ce guide (voir <<target-cypher-query,Définition de la requête du sous-graphe>>) et collez-la directement dans l'éditeur.
3. Cliquez sur l'icône **Run** (Exécuter). AGViewer traitera la requête et affichera dynamiquement le sous-ensemble de nœuds et de relations résultant sur le canevas situé en dessous.
